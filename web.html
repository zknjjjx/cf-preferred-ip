测试域名（验活）

这两个域名就是“测试域名”：程序拿它们逐个候选 IP 建 TLS 实测，能通才入选。必须填你自己部署的域名——谁安装这个项目，就填谁自己的。

扫描参数

选远地区（如美国）时延迟上限建议放宽到 500 以上，否则可能全被延迟筛掉。

推送设置

启用 cfnew 直推（API）
填了推送网址就按网址推（网址里已含 UUID/路径）；与下面 UUID 二选一，网址优先。
直推前需在 cfnew 面板开启「允许 API 管理」（ae=yes）。
启用 GitHub 仓库推送（edgetunnel 拉取用）
Token 只需该仓库 Contents 读写权限。密钥只保存在路由器容器数据里，不会上传到任何地方。
